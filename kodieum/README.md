# Кодиеум — постквантовая схема инкапсуляции ключа

Реализация по проекту методических рекомендаций ТК26 (`Кодиеум_МР.pdf`),
набор параметров `secparam1264` (n=3520, m=12, t=64).

## Структура

- `gf.py` — арифметика в F₂ᵐ (раздел 5.3)
- `gost_primitives.py` — Стрибог-256, Кузнечик, KDF_TREE (используются как
  внешние примитивы, не являющиеся предметом задания; проверены по
  официальным контрольным векторам RFC 7801 и RFC 7836)
- `kem_helpers.py` — `gen_unique_seq`, `gen_weight_vec` (раздел 6.1–6.2)
- `decode.py` — `Decode`, декодирование кода Гоппы (раздел 6.3)
- `kem.py` — `KeyGen`, `Encaps`, `Decaps` (раздел 8)
- `bitvec.py` — упаковка/распаковка двоичных векторов за O(n); без неё
  наращивание больших int побитовым `|=`/`<<` в цикле стоит O(n²)
- `tests/` — юнит-тесты (включая прямые тесты `decode()` с успешным и
  отказным путём, матричных функций `KeyGen`, и внешних ГОСТ-примитивов
  против официальных контрольных векторов RFC 7801/7836) и сквозной
  (round-trip) тест KEM; `tests/doc_hex.py` — декодер нестандартной
  hex-нотации Приложения Б.1
- `ANALYSIS.md` — анализ качества документа (конкретные предложения)
- `CONTROL_EXAMPLES.md` — результаты проверки по каждому контрольному
  примеру Приложения Б (PASS/FAIL + вероятная причина расхождения)
- `DECOMPOSITION.md` — декомпозиция алгоритма на составляющие: какие
  алгоритмы подлежат реализации, их вход/выход, последовательность
  выполнения и соответствие разделам МР

## Запуск тестов

```bash
pip install -r requirements.txt
python -m pytest tests/
```

Полный прогон на реальных параметрах (`n=3520, t=64`) занимает около минуты
(KeyGen ~33с, Decaps ~35с, Encaps <1с — чистый Python, без низкоуровневых
оптимизаций, в соответствии с требованием читаемости кода из задания; при
этом случайное наращивание больших `int` побитовым `|=`/`<<` внутри цикла
исправлено на O(n)-упаковку через `bitvec.py`, см. ниже). В тестах
используются уменьшенные n, t для скорости; раунд-трип на полном масштабе
проверен вручную (см. историю коммитов).

  устранено дублирование кода. Весь набор тестов (39/39) пройден заново
  после исправлений
