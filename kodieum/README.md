# Кодиеум — постквантовая схема инкапсуляции ключа

Реализация по проекту методических рекомендаций ТК26 (`Кодиеум_МР.pdf`),
набор параметров `secparam1264` (n=3520, m=12, t=64).

## Структура

- `gf.py` — арифметика в F₂ᵐ (раздел 5.3)
- `gost_primitives.py` — Стрибог-256, Кузнечик, HKDF (используются как внешние
  примитивы, не являющиеся предметом задания)
- `kem_helpers.py` — `gen_unique_seq`, `gen_weight_vec`, `Decode` (раздел 6)
- `kem.py` — `KeyGen`, `Encaps`, `Decaps` (раздел 8)
- `tests/` — тесты против контрольных примеров из Приложения Б документа

## Запуск тестов

```bash
pip install -r requirements.txt
python -m pytest tests/
```
