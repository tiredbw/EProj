# EProj — учебная практика, постквантовые KEM (ТК26)

Репозиторий на троих: каждый реализует свой вариант задания независимо,
в своей папке, чтобы не конфликтовать в git.

## Этап 1 — ГОСТ-примитивы

[`gost/`](gost/) — собственная реализация хэш-функции «Стрибог»
(ГОСТ 34.11-2018) и блочного шифра «Кузнечик» (ГОСТ 34.12-2018), без
сторонних криптобиблиотек, с проверкой по всем контрольным примерам
стандартов. Выполняется первым: на этих примитивах строятся все три
варианта.

Там же — HMAC и KDF_TREE (Р 50.1.113-2016), построенные на «Стрибоге».

## Варианты

«Кодиеум» реализован на `gost/` целиком, со всеми режимами документа,
сверен с контрольными примерами и снабжён анализом качества документа
(`kodieum/ANALYSIS.md`). «Гиперикум» реализован для всех шести наборов
параметров и сверен с примерами (`giperikum/ANALYSIS.md`). «Земляника»
реализована для всех четырёх наборов; контрольных примеров в её документе
нет (`zemlyanika/ANALYSIS.md`). Все три варианта используют только
собственные «Стрибог» и «Кузнечик» из `gost/`.

Вопросы, на которые тексты проектов не отвечают, собраны в письмо авторам:
[`QUESTIONS_TO_AUTHORS.md`](QUESTIONS_TO_AUTHORS.md).

| Папка | Вариант | Документ |
|---|---|---|
| [`kodieum/`](kodieum/) | Схема инкапсуляции ключа «Кодиеум» | `Кодиеум_МР.pdf` |
| [`giperikum/`](giperikum/) | Схема подписи «Гиперикум» | `Гиперикум_МР.pdf` |
| [`zemlyanika/`](zemlyanika/) | Схема инкапсуляции ключа «Земляника» | `Земляника_МР.pdf` |

Общее задание (`Работы в НГТУ.docx`) одинаково для всех вариантов: реализовать
алгоритмы на Python по проекту методических рекомендаций, проверить по
контрольным примерам из документа, подготовить анализ качества документа.

Каждая папка самодостаточна: свой код, свои тесты, свой README с инструкцией
запуска.

## Запуск

Нужен Python 3.10 или новее (проверено на 3.10.22 и 3.14.8). Из корня репозитория:

```bash
pip install -r requirements.txt
python main.py
python -m pytest
python -m gost.examples
python -m kodieum.examples
python -m giperikum.examples
python -m zemlyanika.examples
```

`python main.py` по очереди запускает наглядные прогоны всех частей и
печатает сводку PASS/FAIL. `python -m pytest` прогоняет все тесты (около минуты; долгие тесты
«Гиперикума» — при `GIPERIKUM_SLOW=1`). `*.examples` печатают каждое
контрольное значение документа: ожидаемое, полученное и итог сверки.

То же в Docker, без установки Python:

```bash
docker build -t eproj .
docker run --rm eproj
docker run --rm eproj python -m pytest
```
