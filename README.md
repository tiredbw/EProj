# EProj — учебная практика, постквантовые KEM (ТК26)

Репозиторий на троих: каждый реализует свой вариант задания независимо,
в своей папке, чтобы не конфликтовать в git.

## Этап 1 — ГОСТ-примитивы

[`gost/`](gost/) — собственная реализация хэш-функции «Стрибог»
(ГОСТ 34.11-2018) и блочного шифра «Кузнечик» (ГОСТ 34.12-2018), без
сторонних криптобиблиотек, с проверкой по всем контрольным примерам
стандартов. Выполняется первым: на этих примитивах строятся все три
варианта.

## Варианты (отложены до завершения этапа 1)

В `kodieum/` пока используется пакет `gostcrypto`; позже его нужно будет
заменить на `gost/`.

| Папка | Вариант | Документ |
|---|---|---|
| [`kodieum/`](kodieum/) | Схема инкапсуляции ключа «Кодиеум» | `Кодиеум_МР.pdf` |
| `giperikum/` | Схема подписи «Гиперикум» | `Гиперикум_МР.pdf` |
| `zemlyanika/` | Схема инкапсуляции ключа «Земляника» | `Земляника_МР.pdf` |

Общее задание (`Работы в НГТУ.docx`) одинаково для всех вариантов: реализовать
алгоритмы на Python по проекту методических рекомендаций, проверить по
контрольным примерам из документа, подготовить анализ качества документа.

Каждая папка самодостаточна: свой код, свои тесты, свой README с инструкцией
запуска.
